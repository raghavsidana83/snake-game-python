# Snake Game 🐍

A classic Snake Game built using Python's built-in Turtle graphics module.

## Features

- Keyboard controls for snake movement
- Food collection and score tracking
- High-score tracking during gameplay
- Snake body growth after eating food
- Screen-boundary wrapping
- Game-over detection
- Restart functionality

## Technologies Used

- Python 3
- Turtle Graphics
- Random module
- Time module

## How to Run

1. Install Python 3 from https://www.python.org/downloads/
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python snake_game.py
   ```

## Controls

| Key | Action |
|---|---|
| Up Arrow | Move up |
| Down Arrow | Move down |
| Left Arrow | Move left |
| Right Arrow | Move right |
| R | Restart after game over |

This project helped me practise Python programming, functions, loops, conditional statements, event handling, and basic game development.
